# Product detail page (Story 2)

Build only the **product detail page** per Story 2 in `AcceptanceCriteria.md`. Do not build Story 3, and **do not integrate the API yet**.

Before writing any code, read and review the following in detail, then briefly summarize what the detail page will include:

- `AcceptanceCriteria.md` — **all of Story 2** (navigation, two-column layout, gallery, vehicle/seller info, contact buttons)
- Product detail UI in the project (mock, screenshot, or design file)
- Theme, UI components, and helpers from earlier steps — **reuse them first; do not recreate unless necessary**
- Home page and mock data from step 3 — **reuse the same dataset when possible**

If the detail page UI is missing, AC and UI conflict, or anything can be interpreted in more than one way, ask first. Do not invent layout or details that are not in these sources.

## Scope

Assemble the detail page to match Story 2:

| Section | AC requirement |
| --- | --- |
| **Navigation** | Clicking a card on the home page opens that product's detail page |
| **Layout** | Clear two-column layout (left and right) |
| **Left (gallery)** | Large image on top, thumbnails below; clicking a thumbnail updates the main image |
| **Right (info)** | Vehicle name + price (large red text), full description, vehicle info box (brand, model, year), seller info box (name, phone, Line) |
| **Call to action** | Large bottom buttons: "ติดต่อผู้ขาย" or "แอดไลน์" |

## Responsive (build with UI in this step)

DoD requires the frontend to be **responsive** — do not defer this.

- Use breakpoints from the theme (step 2)
- **Desktop:** two-column layout (left–right) per AC
- **Mobile/Tablet:** stack left and right vertically; gallery remains usable
- Thumbnails and CTA buttons do not overflow or overlap on small screens

## Logic (no API yet)

- Use **mock data** from step 3 or extend it with multiple images and full detail fields per AC
- Set up a detail route (e.g. `/products/:id`) and load the matching item from mock data by id
- **Wire navigation from the home page** — card click goes to that product's detail page
- Implement gallery logic (thumbnail click updates the main image)
- Contact / Line buttons use mock data (e.g. `tel:` or Line link)

## Do not

- Call the API or connect to the backend
- Build Story 3 (admin page)
- Create new theme / components / helpers if existing ones already cover the need
