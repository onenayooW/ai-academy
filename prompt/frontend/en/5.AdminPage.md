## Responsive (build with UI in this step)

DoD requires the frontend to be **responsive** — do not defer this.

- Use breakpoints from the theme (step 2)
- **Table:** horizontal scroll or adjusted layout on mobile; edit/delete remain usable
- **Form modal:** usable on small screens (full or near-full width); inputs and buttons do not overflow
- Create button and page title remain readable and tappable on mobile

## Logic (no API yet)

- Use **mock data / in-memory state** instead of calling the API
- Implement local CRUD: create, edit, delete; changes reflect in the table immediately
- Open create modal (empty form) and edit modal (prefilled from selected row)
- `[ ยกเลิก ]` closes the modal without saving
- Image upload uses client-side preview (e.g. `URL.createObjectURL`); do not send to backend yet
- Limit truck images to 4; accept only `.png` and `.jpg`
- Implement **client-side validation** per DoD form rules, e.g. duplicate title, negative price or above `99999999`, required fields
- **Wire the home page "จัดการสินค้า" button** to this page

## Do not

- Call the API or connect to the backend
- Create new theme / components / helpers if existing ones already cover the need
