# ตั้งค่าโปรเจกต์ frontend

ก่อนตั้งโปรเจกต์ ให้อ่าน `DefinitionOfDone.md` ที่ให้มาทั้งหมดก่อน แล้วสรุปเฉพาะส่วนที่เกี่ยวกับ frontend ว่าต้องใช้เทคโนโลยีอะไร เวอร์ชันอะไร และมีเงื่อนไขอะไรที่กระทบการ setup

ถ้า DOD ไม่ครบ หรือมีจุดที่ตีความได้มากกว่าหนึ่งแบบ ให้ถามก่อน ห้ามสมมติเอง และห้ามสร้างไฟล์หรือติดตั้งแพ็กเกจจนกว่าจะได้คำตอบ

คำถามให้ถามเฉพาะสิ่งที่จำเป็นต่อการ setup เช่น ชื่อโฟลเดอร์ เวอร์ชันที่ DOD ไม่ได้ระบุ และวิธีต่อ API

เมื่อได้คำตอบครบแล้ว ค่อย setup โปรเจกต์ frontend ให้ตรงกับ DOD เท่านั้น
