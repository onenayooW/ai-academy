# หน้ารายละเอียดสินค้า (Story 2)

ขั้นนี้ทำเฉพาะ **หน้ารายละเอียดสินค้า** ตาม Story 2 ใน `AcceptanceCriteria.md` ยังไม่ทำ Story 3 และ **ยังไม่ integrate API**

ก่อนเขียนโค้ด ให้อ่านและดูแหล่งต่อไปนี้อย่างละเอียด แล้วสรุปสั้นๆ ว่าหน้ารายละเอียดจะประกอบด้วยอะไรบ้าง:

- `AcceptanceCriteria.md` — **Story 2 ทั้งหมด** (การนำทาง, เลย์เอาต์ 2 ฝั่ง, แกลเลอรี, ข้อมูลรถ/ผู้ขาย, ปุ่มติดต่อ)
- UI ของหน้ารายละเอียดในโปรเจกต์ (mock, screenshot หรือไฟล์ออกแบบ)
- theme, UI component และ helper จากขั้นก่อน — **ใช้ซ้ำก่อน ห้ามสร้างใหม่โดยไม่จำเป็น**
- หน้าแรกและ mock data จากขั้น 3 — **ใช้ชุดข้อมูลเดียวกันได้**

ถ้า UI หน้ารายละเอียดไม่พบ หรือ AC กับ UI ขัดกัน หรือมีจุดที่ตีความได้มากกว่าหนึ่งแบบ ให้ถามก่อน ห้ามสมมติ layout หรือรายละเอียดที่ไม่มีในแหล่งเหล่านี้

## ขอบเขตที่ต้องทำ

ประกอบหน้ารายละเอียดให้ครบตาม Story 2:

| ส่วน | ข้อกำหนดจาก AC |
| --- | --- |
| **การนำทาง** | คลิก Card จากหน้าแรกแล้วมาหน้ารายละเอียดของสินค้านั้น |
| **เลย์เอาต์** | แบ่ง 2 ฝั่งหลัก (ซ้าย–ขวา) อย่างชัดเจน |
| **ฝั่งซ้าย (แกลเลอรี)** | รูปใหญ่ด้านบน, Thumbnail เรียงด้านล่าง, คลิก Thumbnail แล้วรูปใหญ่เปลี่ยนตาม |
| **ฝั่งขวา (ข้อมูล)** | ชื่อรถ + ราคา (ตัวใหญ่สีแดง), รายละเอียดครบ, กล่องข้อมูลรถ (ยี่ห้อ, รุ่น, ปี), กล่องข้อมูลผู้ขาย (ชื่อ, เบอร์, Line) |
| **Call to action** | ปุ่มใหญ่ด้านล่าง "ติดต่อผู้ขาย" หรือ "แอดไลน์" |

## Responsive (ทำพร้อม UI ตั้งแต่ขั้นนี้)

DoD กำหนดว่า frontend ต้อง **Responsive** — อย่ารอไปทำทีหลัง

- ใช้ breakpoint จาก theme (ขั้น 2)
- **Desktop:** เลย์เอาต์ 2 ฝั่ง (ซ้าย–ขวา) ตาม AC
- **Mobile/Tablet:** ฝั่งซ้ายและขวา stack เป็นแนวตั้ง, แกลเลอรียังใช้งานได้
- Thumbnail และปุ่ม CTA ไม่ล้นหรือทับกันบนจอเล็ก

## Logic (ยังไม่ต่อ API)

- ใช้ **mock data** เดิมจากขั้น 3 หรือขยายให้มีรูปหลายรูปและรายละเอียดครบตาม AC
- ตั้ง route หน้ารายละเอียด (เช่น `/products/:id`) และดึงข้อมูลจาก mock data ตาม id
- **เชื่อมการนำทางจากหน้าแรก** — คลิก Card แล้วไปหน้ารายละเอียดของสินค้านั้น
- ทำ logic สลับรูปในแกลเลอรี (คลิก Thumbnail → เปลี่ยนรูปใหญ่)
- ปุ่มติดต่อ / แอดไลน์ ใช้ข้อมูลจาก mock data (เช่น `tel:` หรือลิงก์ Line)

## สิ่งที่ห้ามทำ

- ห้ามเรียก API หรือเชื่อม backend
- ห้ามทำ Story 3 (หน้าจัดการสินค้า)
- ห้ามสร้าง theme / component / helper ใหม่ ถ้ามีของเดิมใช้ได้แล้ว

## หลังทำเสร็จ

สรุปสั้นๆ ครอบคลุม:

1. ไฟล์ที่สร้างหรือแก้ไข
2. แต่ละส่วน UI อ้างอิงข้อ AC ข้อใด
3. route และการนำทางจากหน้าแรกทำงานอย่างไร
4. แกลเลอรีและ mock data ทำงานอย่างไร
5. responsive แต่ละ breakpoint ทำงานอย่างไร

หากมีสิ่งใดไม่ชัดเจนหรือมีคำถาม ให้ถามฉันก่อนดำเนินการเสมอ
