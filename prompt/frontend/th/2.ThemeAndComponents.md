# Theme, UI component และ helper

ขั้นนี้ยังไม่ทำหน้าเว็บ ทำเฉพาะ theme หลัก, component ที่ใช้ซ้ำ และ helper function

ก่อนเขียนโค้ด ให้อ่านและดูแหล่งต่อไปนี้ทั้งหมด แล้วสรุปสั้นๆ ว่าจะสร้างอะไร:

- `AcceptanceCriteria.md` — หน้าจอ ชิ้นส่วน UI และพฤติกรรมที่ต้องมี
- `DefinitionOfDone.md` — เฉพาะส่วนที่เกี่ยวกับ frontend
- UI ในโปรเจกต์ (mock, screenshot หรือไฟล์ออกแบบ)
- Design system ในโปรเจกต์ (สี ตัวอักษร ระยะ และ component)

ถ้าไม่พบ UI หรือ design system หรือมีจุดที่ตีความได้มากกว่าหนึ่งแบบ ให้ถามก่อน ห้ามสมมติสี ขนาด หรือ component ที่ไม่มีในแหล่งเหล่านี้ และห้ามสร้างไฟล์จนกว่าจะได้คำตอบ

คำถามให้ถามเฉพาะสิ่งที่จำเป็น เช่น ที่อยู่ของ design system และ component ที่ AC ต้องใช้แต่ design system ไม่มี

เมื่อแหล่งครบและชัดแล้ว ค่อยสร้างเฉพาะ 3 ส่วนนี้ ให้เข้ากับโปรเจกต์ frontend ที่ตั้งไว้แล้ว:

1. **Theme หลัก** — design token ของโปรเจกต์ (สี ตัวอักษร ระยะ รัศมี **breakpoint**) ให้ตรงกับ design system และใช้ซ้ำได้ทั้งแอป
2. **UI component** — เฉพาะชิ้นที่ AC ต้องใช้ และจัดสไตล์ตาม design system เท่านั้น ยังไม่ประกอบเป็นหน้า — **ทุก component ต้อง responsive ตั้งแต่ต้น** ใช้ breakpoint จาก theme
3. **Helper function** — ฟังก์ชันที่หน้าจอจะต้องใช้ตาม AC และ DoD เช่น จัดรูปแบบราคาและข้อความข้อมูลรถ, ลิงก์ติดต่อ, ตรวจรูปและราคา ห้ามเพิ่มฟังก์ชันที่สเปกไม่ได้ใช้

DoD กำหนดว่า frontend ต้อง **Responsive** — อย่ารอไปทำทีหลัง ให้วาง breakpoint และ component ให้รองรับ mobile/tablet/desktop ตั้งแต่ขั้นนี้

หลังทำให้สรุปสั้นๆ ว่าสร้างไฟล์อะไรบ้าง แต่ละชิ้นรองรับข้อ AC ข้อใด และ breakpoint ที่ใช้

หากมีสิ่งใดไม่ชัดเจนหรือมีคำถาม ให้ถามฉันก่อนดำเนินการเสมอ
