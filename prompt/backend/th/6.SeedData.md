# Seed Data

**ทำหลัง:** `4.Implement.md` และ `5.CreateUnitTest.md`

จาก `docs/DB/*.md` ให้สร้างหรืออัปเดต `docs/DataExample/*.csv`

## กฎ

- หนึ่งตารางต่อหนึ่งไฟล์ หัวคอลัมน์ต้องตรงกับชื่อฟิลด์ใน DB
- ใส่ค่า FK ที่จำเป็นทั้งหมด
- อนุญาตให้ใช้ ID คงที่
- ใส่ข้อมูลเพียงพอให้ทดสอบ filtering และ sorting ตาม AC/DoD

## ลำดับไฟล์

ประมวลผลตารางตาม **ลำดับ insert ที่ไม่ละเมิด FK** จากสรุปท้าย `2.DesignDatabase.md` (ข้อ 3)

ตัวอย่างลำดับสำหรับ Truck2Hand (ปรับตาม schema จริงถ้าต่างจากนี้):

1. `vehicle_types`
2. `brands`
3. `models`
4. `sellers`
5. `products`
6. `product_images`

## หมายเหตุ CSV

หากค่าฟิลด์มี comma ให้ใช้รูปแบบ CSV แบบ quoted หรือแจ้งฉันว่า seed parser ต้องรองรับ

หากมีสิ่งใดไม่ชัดเจนหรือมีคำถาม ให้ถามฉันก่อนดำเนินการเสมอ
