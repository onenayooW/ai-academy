## Rules

- One table per file; column headers must match DB field names
- Include all required FK values
- Fixed IDs are allowed
- Include enough data to test filtering and sorting per AC/DoD

## File order

Process tables in **FK-safe insert order** from the summary at the end of `2.DesignDatabase.md` (item 3)

Example order for Truck2Hand (adjust if the actual schema differs):

1. `vehicle_types`
2. `brands`
3. `models`
4. `sellers`
5. `products`
6. `product_images`
