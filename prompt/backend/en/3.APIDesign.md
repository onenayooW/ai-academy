## Output requirements

- Save the files to: `[path, e.g. /project/docs/API]`
- Group files by resource and endpoint
- One endpoint per file
- Use an operation prefix such as `{retrieve,create,update,delete}_...` and the `.md` extension

### File structure

Each operation file should follow this structure (separate each operation with `---` when multiple operations share one file):

**Base Endpoint:** `http://localhost:8080`

**Auth** (if login or roles are within scope):

- Specify the Bearer token requirement and reference `docs/API/authorization.md`, or describe the roles allowed for each endpoint.
- If authentication is outside the scope, omit this section.

**Validation / business rules** (for that resource only):

- Expected HTTP statuses, such as `400`, `404`, and `409`
- Rules defined in the DoD, such as duplicate names, prices, blocklists, maximum image count, and so on

**Operation block template:**

```markdown
{OPERATION_NAME_IN_UPPER_SNAKE_CASE}: {Short Thai description explaining which page or feature uses the operation}

Method: GET | POST | PUT | PATCH | DELETE
Path: `/v1/api/...`

Path Params:

| Field | Type | Description |
| --- | --- | --- |
| ... | ... | ... |

If there are no path parameters: `Path Params: -`

Query Params:

| Field | Type | Description | Default |
| --- | --- | --- | --- |
| ... | ... | ... | ... |

If there are no query parameters: `Query Params: -`

Request Body (if applicable):

- For `application/json`, use a table with Field, Type, and Description.
- For `multipart/form-data`, use a table with Field, Type, and Description; use `File` as the type for images.

Response Body:

- Use a table with Field, Type, and Description for nested records.
- For paginated lists, include `page`, `size`, `total`, and `items`.
- If the response contains nested record objects, document each one under a separate **Record Object (...)** heading.

Error Handling (when multiple cases exist):

| HTTP | When |
| --- | --- |
| ... | ... |
```

If anything is unclear or you have any questions, always ask me before proceeding.
