# Seed Data

From `docs/DB/*.md`, create or update `docs/DataExample/*.csv`.

## Rules

- One table per file; headers must match the DB field names
- Include all required FK values
- Fixed IDs are allowed
- Include enough data to demonstrate filtering and sorting according to the AC/DoD

## File order

Process tables in this order to satisfy foreign keys:

1. `vehicle_types`
2. `brands`
3. `models`
4. `sellers`
5. `products`
6. `product_images`

## CSV notes

If a field value contains a comma, use quoted CSV format or notify me that the seed parser must support it.

If anything is unclear or you have any questions, always ask me before proceeding.
